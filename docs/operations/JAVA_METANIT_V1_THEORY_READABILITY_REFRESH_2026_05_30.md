# Java Metanit v1 Theory Readability Refresh — 2026-05-30

## Контекст
Пользовательский аудит показал, что часть уроков Java-курса отображается как слитный текст с примесями синтаксических фрагментов и служебных строк источника. В таком виде материал трудно изучать.

## Что исправлено
1. Обновлен генератор `материалы/java_metanit_v1/build_course.py`.
2. Теоретический текст теперь извлекается из семантических блоков (`h1-h4`, `p`, `li`, `blockquote`) вместо сплошного `container.get_text(...)`.
3. Блоки кода (`pre`) исключены из текстового слоя и остаются только в секции `### Пример кода`.
4. Добавлена очистка служебных артефактов:
- `Последнее обновление: dd.mm.yyyy`;
- `Назад Содержание Вперед`.
5. Добавлена дедупликация повторяющихся строк и повторяющихся предложений в теории.

## Почему сделано именно так
1. Фикс на уровне генератора устраняет причину дефекта для всего курса, а не только для нескольких записей в базе.
2. Это предотвращает повторное появление проблемы при последующих reseed-миграциях.
3. Разделение «теория/код» делает уроки предсказуемыми: текст объясняет, code-блоки демонстрируют пример.

## Порядок применения в production
1. Доставить изменения в репозиторий на сервер.
2. Выполнить `backend/cmd/migrator` (или `./bin/leonovcare-migrator`).
3. Перезапустить `leonovcare-api` и `leonovcare-worker`.
4. Проверить `/healthz`, `/readyz`, затем выборочно открыть Java-уроки из OOP-модуля.
