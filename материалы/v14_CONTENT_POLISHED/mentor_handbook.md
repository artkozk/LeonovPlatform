# Handbook для наставника v14

## Принцип ответа
Сначала спроси студента о наблюдаемом результате: ввод, вывод, stderr, команда запуска. Не выдавай готовое решение, если можно локализовать ошибку одним вопросом.

## Частые ошибки
- точный stdout нарушен лишним словом;
- SQL не сортирует результат;
- transaction-задача делает SELECT вместо BEGIN/COMMIT/ROLLBACK;
- FastAPI healthcheck возвращает массив вместо объекта;
- Docker/CI задача не содержит проверяемого файла;
- Git-задача оставляет грязное рабочее дерево.

## Эскалация
Эскалируй, если публичный пример противоречит hidden-проверке, IDE-плагин не видит существующий файл или корректное решение падает на инфраструктуре.
