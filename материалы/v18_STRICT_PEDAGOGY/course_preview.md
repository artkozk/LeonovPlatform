### Шаг 1. Смысл (theory)

Программа — это набор команд, которые компьютер выполняет по порядку. В Python команда обычно занимает одну строку кода. Когда ты запускаешь файл, Python читает первую строку, выполняет её, затем переходит к следующей. Поэтому порядок строк важен: если поменять строки местами, результат тоже может измениться.

Самая маленькая полезная команда для старта — `print("Привет")`. Она показывает текст на экране. Экранный результат после запуска называется выводом. Кавычки не появляются в выводе: они нужны Python только для того, чтобы понять, где начинается и заканчивается текст.

Минимальный пример:

```python
print("Привет")
print("Я пишу код")
```

Первая строка выводит `Привет`. Вторая строка выводит `Я пишу код`. Python не выбирает строки сам и не выполняет их случайно: он идёт сверху вниз.

Что важно: автопроверка сравнивает вывод точно. Для неё `Привет`, `привет` и `Привет ` с пробелом в конце — разные результаты. Перед отправкой смотри не только на смысл, но и на регистр, пробелы и лишние строки.

Частая ошибка: добавить пояснение в вывод, хотя условие просит только точный текст. Если нужно вывести `Привет`, строка `Ответ: Привет` уже не подходит.

### Шаг 2. print (theory)

`print()` — это команда Python для вывода. Слово `print` говорит, что нужно что-то показать. Скобки говорят, какие данные получает команда. Кавычки говорят, что внутри находится обычный текст.

Разберём строку:

```python
print("Код работает")
```

`print` — имя команды. Открывающая скобка `(` начинает место для данных. Текст `Код работает` записан в кавычках. Закрывающая скобка `)` завершает команду. После запуска Python выводит:

```text
Код работает
```

Кавычки в вывод не попадают. Они нужны только в коде. Если забыть кавычку, Python не поймёт, где текст заканчивается. Если забыть скобку, команда останется незавершённой. Ошибка в таком месте не означает, что “всё сломано”. Это сигнал: Python не смог прочитать команду.

Самые частые ошибки в первом уроке: пропущена кавычка, пропущена скобка, лишний `print`, лишний текст внутри кавычек или строки стоят не в том порядке.

Что важно: когда условие просит вывести одну строку, не добавляй приветствие, пояснение или пустую строку. Пиши ровно тот вывод, который указан в примере.

### Шаг 1. Что это (theory)

Во втором уроке появляется ввод данных. До этого программа сама решала, что вывести. Теперь она сможет дождаться значения от человека и использовать его в коде.

Команда `input()` читает одну строку. Важно: результат `input()` всегда строка, даже если человек ввёл цифры. Если ввести `2`, Python получает текст `"2"`, а не число `2`. Поэтому выражение `"2" + "3"` даёт строку `"23"`, потому что для текста знак `+` склеивает строки.

Чтобы считать целое число, используют `int(input())`. Сначала `input()` получает строку, потом `int(...)` превращает её в число. Если внутри не число, например `кот`, Python выдаст ошибку. Это нормально: программа не может сложить число и слово без понятного правила.

Для дробных чисел используют `float(...)`: например `2.5`. Арифметика работает с числами: `+`, `-`, `*`, `/`, `//`, `%`.

Что важно: сначала прочитай данные, потом преобразуй тип, потом делай вычисление. Не смешивай текст и числа в одной операции без преобразования.

Самопроверка: почему `input()` после ввода `7` ещё не даёт число для сложения?

Минимальный пример для этой части:

```python
raw = input()
number = int(raw)
print(number + 1)
```

Разбор: первая строка получает текст, вторая превращает текст в число, третья выполняет арифметику.

Частая ошибка: читать пример только глазами и не запускать его. Запусти маленький фрагмент и сравни вывод с тем, что ожидаешь увидеть.

### Шаг 2. Минимальный пример (theory)

Минимальная программа с вводом:

```python
name = input()
print("Привет, " + name)
```

Первая строка ждёт ввод и сохраняет его в переменную `name`. Переменная — это имя для значения, чтобы использовать его позже. Вторая строка склеивает текст `Привет, ` и введённое имя, затем выводит результат.

Пример с числом:

```python
age = int(input())
print(age + 1)
```

Сначала `input()` получает строку. Потом `int(...)` превращает её в целое число. После этого `age + 1` работает как арифметика, а не как склейка текста.

Два числа в одной строке читают так:

```python
a, b = input().split()
a = int(a)
b = int(b)
print(a + b)
```

`split()` делит строку по пробелам. Затем каждую часть нужно отдельно превратить в число.

Частая ошибка: написать `age = input()` и потом `print(age + 1)`. Python не складывает строку и число. Если видишь такую ошибку, проверь, где должен быть `int(...)` или `float(...)`.

## 1.3 Строки

### Шаг 1. Что это (theory)

Строка — это текстовое значение. Имя, сообщение, адрес страницы, команда из консоли, строка из файла — всё это часто попадает в программу как текст. В Python строку записывают в кавычках: `"hello"` или `"Привет"`.

Строку можно читать через `input()`, сохранять в переменную и обрабатывать. У строки есть позиции символов. Позиция называется индексом. Первый символ имеет индекс `0`, а не `1`. Это непривычно, но важно: `text[0]` берёт первый символ.

Срез берёт часть строки: `text[0:3]` берёт символы с позиции `0` до позиции `3`, не включая позицию `3`. Методы строк помогают чистить и менять текст: `strip()` убирает пробелы по краям, `lower()` переводит буквы в нижний регистр, `replace()` заменяет один фрагмент на другой, `split()` делит строку на части.

Что важно: строка не меняется сама. Метод возвращает новую строку. Если написать `name.strip()`, но не сохранить результат, переменная `name` останется прежней.

Частая ошибка: вызвать метод и забыть присваивание. Правильно так: `name = name.strip()`.

Самопроверка: почему у первого символа индекс `0`, а не `1`, нужно просто запомнить и проверять на маленьких примерах.

Минимальный пример для этой части:

```python
text = input()
print(text.strip())
```

Разбор: первая строка получает текст, вторая выводит новую строку без пробелов по краям.

### Шаг 2. Минимальный пример (theory)

Разберём маленькую программу:

```python
text = input()
clean = text.strip().lower()
print(clean)
```

Первая строка читает текст. Вторая строка делает две операции: `strip()` убирает пробелы по краям, затем `lower()` приводит буквы к нижнему регистру. Результат сохраняется в новую переменную `clean`. Третья строка выводит очищенный текст.

Пример со срезом:

```python
word = input()
print(word[0:3])
```

Если ввести `python`, вывод будет `pyt`. Срез `0:3` берёт позиции `0`, `1` и `2`.

Пример с заменой:

```python
title = input()
print(title.replace(" ", "-"))
```

Пробелы заменяются дефисами. Это похоже на подготовку коротких адресов страниц.

Частая ошибка: ожидать, что `text.strip()` изменит `text` без присваивания. Строки в Python неизменяемые: метод возвращает новый результат.

Самопроверка: что выведет `print("Python"[0:2])`?

## 1.4 bool и None

- Нагрузка: 2.2 ч
- Темы: Python Core
- Навыки: None как текст: не путай None и строку, bool и None: basics, bool и None: checked artifact, bool и None: mini project, bool и None: minimal example, Положительное: получи bool из сравнения, Пустая строка: проверь truthiness строки, Равно: сравни два числа

### Шаг 1. Что это (theory)

`bool` — это тип для двух ответов: `True` и `False`. Такие значения появляются после сравнений. Например, `5 > 3` даёт `True`, а `5 == 3` даёт `False`. В backend-коде такие проверки встречаются постоянно: заполнено ли поле, совпал ли пароль, есть ли доступ, найден ли объект.

`None` означает отсутствие значения. Это не строка `"None"`, не ноль и не пустая строка. `None` используют, когда значения пока нет или функция позже явно вернёт отсутствие результата.

Сравнения пишутся так: `==` проверяет равенство, `!=` проверяет неравенство, `>`, `<`, `>=`, `<=` сравнивают порядок чисел. Для проверки `None` используют `is None`, потому что так код яснее показывает намерение.

Есть ещё идея truthy и falsy: пустая строка после очистки считается ложной, непустая — истинной. Но `0`, пустая строка и `None` — разные вещи. Не смешивай их без причины.

Частая ошибка: проверять `value == None`. Работать может, но в Python принято писать `value is None`.

Самопроверка: чем отличается пустая строка `""` от `None`?

Минимальный пример для этой части:

```python
value = None
print(value is None)
```

Разбор: первая строка создаёт отсутствие значения, вторая проверяет именно это состояние.

### Шаг 2. Минимальный пример (theory)

Минимальный пример со сравнением:

```python
age = int(input())
print(age >= 18)
```

Первая строка читает число. Вторая строка сравнивает его с `18` и выводит результат сравнения: `True` или `False`. Здесь пока нет выбора ветки программы, только сам ответ сравнения.

Пример с пустой строкой:

```python
text = input().strip()
print(bool(text))
```

`strip()` убирает пробелы по краям. `bool(text)` показывает, считается ли строка заполненной. Пустая строка даст `False`, непустая — `True`.

Пример с `None`:

```python
value = None
print(value is None)
```

Так проверяют именно отсутствие значения. Если написать строку `"None"`, это будет обычный текст, а не специальное значение.

Частая ошибка: думать, что `0`, `""` и `None` всегда одно и то же. Они могут вести себя как ложные значения, но смысл у них разный.

### Шаг 1. Что это (theory)

Условие позволяет программе выбрать, какие строки выполнить. До этого код шёл прямо сверху вниз. Теперь можно сказать: если проверка истинна, выполни один блок, иначе выполни другой.

В Python условие начинается с `if`. После проверки ставится двоеточие. Строки внутри ветки пишутся с отступом. Отступ — это часть синтаксиса, а не украшение. По отступу Python понимает, какие команды относятся к условию.

Пример задачи из обычной жизни: прочитать возраст и вывести, можно ли войти. Если возраст 18 или больше, выводим `Можно`. Иначе выводим `Нельзя`.

`else` задаёт ветку для всех остальных случаев. `elif` добавляет ещё одну проверку между `if` и `else`. Порядок проверок важен: Python выбирает первую подходящую ветку.

Частая ошибка: написать `=` вместо `==`. Один знак равенства присваивает значение, два знака сравнивают значения. В условии для проверки равенства нужен `==`.

Самопроверка: почему строки внутри `if` должны быть с одинаковым отступом?

Минимальный пример для этой части:

```python
age = int(input())
if age >= 18:
    print("Можно")
else:
    print("Нельзя")
```

Разбор: проверка выбирает одну из двух веток, а отступ показывает команды внутри веток.

### Шаг 2. Минимальный пример (theory)

Разберём программу:

```python
age = int(input())
if age >= 18:
    print("Можно")
else:
    print("Нельзя")
```

Первая строка читает возраст как число. Строка `if age >= 18:` проверяет условие. Если оно истинно, выполняется команда с отступом под `if`: вывод `Можно`. Если условие ложно, Python переходит к `else` и выполняет команду под ним.

Пример с тремя ветками:

```python
number = int(input())
if number > 0:
    print("плюс")
elif number == 0:
    print("ноль")
else:
    print("минус")
```

Сначала проверяется положительное число. Потом отдельно проверяется ноль. Всё остальное попадает в `else`.

Что важно: границы нужно читать внимательно. Условие `age >= 18` включает 18. Условие `age > 18` не включает 18.

Частая ошибка: поставить правильное условие, но забыть отступ у строки `print`.

### Шаг 1. Что это (theory)

У каждого значения в Python есть тип. Тип отвечает на вопрос: что это за значение и какие операции с ним возможны. `"42"` — строка, `42` — целое число, `42.0` — дробное число, `True` — булево значение.

Переменная хранит ссылку на значение. Когда ты пишешь `x = 10`, имя `x` начинает указывать на число `10`. Если потом написать `x = 20`, имя `x` начинает указывать на другое значение. Старое число не “переписывается” внутри переменной, просто имя связано с новым значением.

Функция `type(value)` показывает тип значения. Для вывода удобного имени можно использовать `type(value).__name__`. Это помогает диагностировать ошибки: например, понять, почему вместо сложения чисел получилась склейка строк.

Что важно: преобразование создаёт новое значение другого типа. `int("42")` не меняет строку `"42"`, а возвращает число `42`.

Частая ошибка: считать, что переменная навсегда привязана к первому типу. В Python имя можно связать с другим значением, но читать такой код становится сложнее.

Самопроверка: чем отличается `"5"` от `5`?

Минимальный пример для этой части:

```python
raw = input()
print(type(raw).__name__)
```

Разбор: ввод сохраняется как строка, а `type(...).__name__` показывает короткое имя типа.

### Шаг 2. Минимальный пример (theory)

Разберём программу:

```python
value = input()
print(type(value).__name__)
number = int(value)
print(type(number).__name__)
```

Первая строка читает ввод. Даже если введено `123`, переменная `value` содержит строку. Поэтому первый вывод будет `str`. Затем `int(value)` создаёт целое число и сохраняет его в `number`. Второй вывод будет `int`.

Пример с переприсваиванием:

```python
name = "Анна"
name = "Олег"
print(name)
```

Вывод будет `Олег`, потому что вторая строка связала имя `name` с новым значением.

Пример с двумя именами:

```python
first = "кот"
second = first
first = "пёс"
print(second)
```

Вывод будет `кот`. Имя `second` сохранило ссылку на старое строковое значение.

Частая ошибка: смотреть только на имя переменной и забывать, какое значение и какой тип сейчас внутри.

Самопроверка: какой тип у результата `float("2.5")`?

### Шаг 1. Что это (theory)

Цикл нужен, когда одну и ту же команду нужно выполнить несколько раз. Без цикла пришлось бы писать много одинаковых строк. В Python чаще всего используют `for` и `while`.

`for` удобен, когда заранее понятно, сколько повторений нужно. Например, `range(1, 4)` даёт числа `1`, `2`, `3`. Цикл берёт каждое число по очереди и выполняет блок команд с отступом.

`while` удобен, когда повторение зависит от условия. Он выполняет блок, пока условие истинно. Важно следить, чтобы условие когда-нибудь стало ложным, иначе программа может повторяться бесконечно.

`break` останавливает цикл раньше времени. `continue` пропускает оставшуюся часть текущего повторения и переходит к следующему.

Что важно: тело цикла пишется с отступом. Переменная внутри `for` получает новое значение на каждом повторении.

Частая ошибка: забыть изменить значение в `while`. Тогда условие остаётся истинным слишком долго.

Самопроверка: сколько строк выведет цикл по `range(1, 4)`?

Минимальный пример для этой части:

```python
for number in range(1, 4):
    print(number)
```

Разбор: цикл берёт числа по очереди и выполняет команду вывода для каждого числа.

### Шаг 2. Минимальный пример (theory)

Пример с `for`:

```python
for number in range(1, 4):
    print(number)
```

`range(1, 4)` даёт 1, 2 и 3. На первом повторении `number` равен 1, на втором — 2, на третьем — 3. Команда `print(number)` выполняется каждый раз.

Пример суммы:

```python
n = int(input())
total = 0
for number in range(1, n + 1):
    total = total + number
print(total)
```

`total` начинается с нуля. На каждом повторении к нему прибавляется очередное число. После цикла выводится итог.

Пример с `while`:

```python
count = int(input())
while count > 0:
    print(count)
    count = count - 1
```

После каждого вывода значение уменьшается. Поэтому цикл остановится.

Частая ошибка: поставить `print(total)` с отступом внутри цикла, когда нужен только итог после цикла.

Самопроверка: почему `n + 1` нужен в `range(1, n + 1)`?

## 1.8 Списки

- Нагрузка: 2.5 ч
- Темы: Python Core
- Навыки: Append: добавь элемент, Split: сделай список из строки, Индекс: возьми первый элемент, Ошибка индекса: исправь последний индекс, Списки: basics, Списки: checked artifact, Списки: mini project, Списки: minimal example

### Шаг 1. Что это (theory)

Список хранит несколько значений в одном порядке. Например, список покупок, список задач, список строк из файла. В Python список записывают в квадратных скобках: `items = ["хлеб", "молоко"]`.

У каждого элемента есть индекс. Как и в строках, первый индекс — `0`. `items[0]` берёт первый элемент, `items[-1]` — последний. Метод `append()` добавляет элемент в конец списка.

Список можно менять: заменить элемент по индексу, добавить новый, удалить позже в следующих темах. Это отличие от строк: строка не меняется сама, а список изменяемый.

Важно отличать копию от второго имени для того же списка. Если написать `second = first`, оба имени указывают на один список. Если нужен отдельный список, используй `first.copy()`.

Строку можно превратить в список слов через `split()`. Это часто нужно, когда ввод содержит несколько значений.

Частая ошибка: обратиться к индексу, которого нет. Если в списке два элемента, последний индекс — `1`, а не `2`.

Самопроверка: какой индекс у первого элемента списка?

Минимальный пример для этой части:

```python
items = ["api", "data"]
items.append("dev")
print(len(items))
```

Разбор: список хранит несколько значений, `append` добавляет новое, `len` считает элементы.

### Шаг 2. Минимальный пример (theory)

Разберём список:

```python
items = ["api", "data"]
items.append("dev")
print(items[0])
print(len(items))
```

Первая строка создаёт список из двух строк. `append("dev")` добавляет третий элемент в конец. `items[0]` берёт первый элемент — `api`. `len(items)` показывает длину списка, теперь это `3`.

Пример изменения:

```python
items = ["черновик", "готово"]
items[0] = "старт"
print(items[0])
```

Список изменяемый, поэтому элемент с индексом `0` можно заменить.

Пример копии:

```python

copy.append("b")
print(len(base))
```

Вывод будет `1`, потому что изменяли копию, а не исходный список.

Частая ошибка: написать `items[2]` для списка из двух элементов. Индексы начинаются с нуля, поэтому элементы имеют индексы `0` и `1`.

### Шаг 1. Что это (theory)

Функция — это именованный кусок кода, который можно вызвать несколько раз. Она помогает не копировать одинаковые действия и делает программу понятнее. В backend-разработке функции считают цену, проверяют данные, собирают ответ, преобразуют строки и выполняют небольшие правила предметной области.

Функцию объявляют через `def`. В круглых скобках указывают параметры — значения, которые функция получает при вызове. `return` возвращает результат наружу. Это важно: `print` только показывает текст на экране, а `return` отдаёт значение тому коду, который вызвал функцию.

Пример:

```python
def add(a, b):
    return a + b

result = add(2, 3)
print(result)
```

Функция `add` получает два числа и возвращает сумму. Затем результат сохраняется в переменную и выводится.

Что важно: код внутри функции пишется с отступом. Если функция должна отдавать значение для проверки, нужен `return`, а не `print`.

Частая ошибка: напечатать результат внутри функции и забыть вернуть его. Такая функция выглядит работающей глазами, но другой код не получает значение.

Самопроверка: чем `return value` отличается от `print(value)`?

### Шаг 2. Минимальный пример (theory)

Разберём функцию:

```python
def greet(name):
    return "Привет, " + name

message = greet("Анна")
print(message)
```

Строка `def greet(name):` создаёт функцию с параметром `name`. Когда вызывается `greet("Анна")`, внутри функции `name` получает значение `"Анна"`. Строка `return "Привет, " + name` возвращает готовую строку. После этого результат попадает в переменную `message`.

Параметров может быть несколько:

```python
def area(width, height):
    return width * height
```

Функция получает ширину и высоту, возвращает произведение. Она не читает ввод сама и не выводит текст сама. Такую функцию проще проверять.

Параметр может иметь значение по умолчанию:

```python
def repeat(word, times=2):
    return word * times
```

Если второй аргумент не передать, используется `2`.

Частая ошибка: забыть вызвать функцию. Одного объявления `def` недостаточно: код внутри выполнится только при вызове.

Самопроверка: что вернёт `area(3, 4)`?

### Шаг 1. Что это (theory)

Кортеж похож на список, но обычно используется для небольшого набора связанных значений, который не нужно менять. Координата точки, пара чисел, результат из двух значений — хорошие примеры для кортежа.

Кортеж записывают в круглых скобках: `point = (10, 20)`. Элементы тоже доступны по индексам: `point[0]` берёт первое значение, `point[1]` — второе. Кортеж можно распаковать: `x, y = point`.

Главное отличие от списка: кортеж не меняют по месту. Если нужна новая координата, создают новый кортеж. Это делает такие данные более предсказуемыми: случайный код не изменит точку внутри программы.

Функция может вернуть кортеж. Так удобно вернуть сразу два значения без создания отдельного объекта.

Что важно: кортеж с одним элементом пишется с запятой: `(value,)`. Без запятой это просто значение в скобках.

Частая ошибка: попытаться изменить элемент кортежа через индекс. Python не разрешит это, потому что кортеж неизменяемый.

Самопроверка: что хранит `point = (3, 5)`?

Минимальный пример для этой части:

```python
point = (3, 5)
x, y = point
print(x + y)
```

Разбор: кортеж хранит два значения, распаковка кладёт их в переменные `x` и `y`.

### Шаг 2. Минимальный пример (theory)

Пример координаты:

```python
point = (3, 5)
print(point[0])
print(point[1])
```

Первый вывод — `3`, второй — `5`. Индексы работают так же, как у строк и списков: первый индекс равен `0`.

Пример распаковки:

```python
point = (3, 5)
x, y = point
print(x + y)
```

Python берёт первое значение кортежа в `x`, второе — в `y`. Вывод будет `8`.

Пример функции:

```python
def move(point, dx, dy):
    x, y = point
    return (x + dx, y + dy)
```

Функция получает точку и сдвиг, распаковывает координаты и возвращает новый кортеж. Исходная точка не меняется.

Частая ошибка: писать `point[0] = 10`. Для кортежа так нельзя. Создай новый кортеж с нужными значениями.

Самопроверка: зачем в функции `move` возвращается новый кортеж?
