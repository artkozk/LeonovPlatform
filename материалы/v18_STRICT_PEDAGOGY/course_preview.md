## Пример первого урока
### 1. Смысл [theory]
**Что это:** программа — это набор строк, которые Python выполняет сверху вниз

**Зачем:** сначала нужно увидеть, как код превращается в точный вывод

После урока ты сможешь: написать строку `print(...)`, вывести текст в кавычках и исправить простую синтаксическую ошибку.

**Частая ошибка:** лишний символ, пропущенная кавычка или лишняя строка меняют результат проверки

### 2. Что делает print [test]
Ответь на вопросы только про `print`, кавычки и порядок строк.

### 3. Первый вывод [practice]
**Коротко:** выведи одну точную строку

### Условие
Напиши одну строку кода, которая выводит `Привет, Python!`.

### Вход
Нет входных данных.

### Выход
```text
Привет, Python!
```

### Что проверить
Проверь кавычки, скобки, регистр и лишние строки.

### 8. Мини-практика [project]
**Коротко:** собери маленький файл с тремя строками вывода

### Условие
В файле `main.py` выведи три строки: `Я пишу код`, `Python читает сверху вниз`, `Ошибки можно исправлять`.

### Вход
Нет входных данных.

### Выход
Три строки в указанном порядке.

### Что проверить
Запусти файл и сравни каждую строку. Не добавляй объяснений в вывод.

### 9. Проверка [test]

### 10. Контрольный артефакт [project]
**Коротко:** закрепи урок в одном маленьком файле

### Условие
Создай `main.py`, где есть один рабочий пример по теме `Первый код`. В `README.md` одной фразой опиши, какой крайний случай ты проверил.

### Вход
Данные берутся так, как уже показано в уроке.

### Выход
Команда запуска выполняется без ручных правок.

### Что проверить
Запусти файл два раза. Результат должен быть одинаковым и без лишнего вывода.
