# Student FAQ v18

## 1. Почему публичный пример проходит, а скрытая проверка нет?
Публичный пример проверяет только один путь. Проверь крайний случай: пустой ввод, границу числа, сортировку, лишний stdout, 401/404/422 или грязное Git-состояние.

## 2. Как читать ошибку Python?
Сначала найди строку traceback, где указан твой файл. Потом прочитай тип ошибки и последнюю строку сообщения. Исправляй одну причину за раз.

## 3. Почему лишний print ломает задачу?
Проверка сравнивает точный вывод. Любая дополнительная строка становится частью stdout и считается ошибкой.

## 4. Почему input возвращает строку?
Клавиатурный ввод приходит текстом. Для чисел явно используй int или float после того, как это объяснено в уроке.

## 5. Почему нельзя использовать будущие темы раньше времени?

## Первые уроки: частые вопросы после редакторской правки 2026-05-03

### Почему `print("Привет")` выводит текст без кавычек?

Кавычки нужны Python, чтобы отличить текст от кода. В вывод попадает содержимое строки, а не сами кавычки.

### Почему проверка не принимает ответ, если смысл тот же?

Проверка сравнивает вывод точно: регистр, пробелы, порядок строк и лишний текст. Если нужно вывести `Готово`, строка `Ответ: Готово` уже другая.

### Почему `input()` не даёт число?

`input()` всегда возвращает строку. Для целого числа используй `int(input())`, для дробного — `float(input())`.

### Почему `"2" + "3"` даёт `23`?

Это строки. Знак `+` для строк склеивает текст. Для сложения чисел сначала преобразуй обе строки через `int()`.

### Почему `name.strip()` не убрал пробелы?

Метод вернул новую строку, но исходная переменная не изменилась. Запиши `name = name.strip()`.

### Почему в условии нужен `==`, а не `=`?

`=` присваивает значение. `==` сравнивает два значения и возвращает `True` или `False`.

### Почему функция печатает правильный ответ, но проверка падает?

В задачах на функции проверка обычно ждёт возвращаемое значение. Используй `return`, а не `print`, если условие просит реализовать функцию.

## FastAPI: почему проверка не принимает endpoint?
Сначала сравни метод и путь в условии с кодом. Если написано `GET /health`, в коде должен быть именно `@app.get('/health')`. Если вместо этого написать `POST`, другой путь или вернуть другой JSON, проверка отклонит решение. В первых FastAPI-уроках не нужно добавлять базу данных, auth или Docker: эти темы идут позже.
